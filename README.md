# BombaVR
VR game for Oculus Quest platform.

## YouTube presentation:
https://www.youtube.com/watch?v=i9hHT4M894o

## Game goal:
Solve 5 puzzles in the suitecase before 5 minutes to win the game.
Follow your assistant instructions to decipher puzzles.

## Tech-stack:
C#, Unity.
